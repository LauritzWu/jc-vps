# JC · sing-box VPS 管理工具

面向个人 VPS 的 sing-box 管理工具。使用官方 APT 版 sing-box，提供五协议安装向导，支持选择 IPv4 或 IPv6 节点地址，并可发布带密码的 HTTPS 订阅。

## 一键安装 v1.2.0

在 VPS 的 root Bash 会话中运行。入口需要 curl。安装脚本、管理脚本、客户端模板和后续的 `jc` 命令均使用同一提交。

```bash
revision=27c778b721f5ae6cef9b77d78c493a209a9ee8f0
s=$(curl -4fsSL -m 25 "https://raw.githubusercontent.com/LauritzWu/jc-vps/$revision/bootstrap.sh") &&
  bash -c "$s" -- "$revision"
```

主菜单选「1 一键安装 sing-box」或直接回车。确认安装时回车继续，安装完成后回车查看节点。详见 [v1.2.0 发布说明](https://github.com/LauritzWu/jc-vps/releases/tag/v1.2.0)。

**已验收范围**为 Ubuntu 24.04 LTS 和 Debian 13，均为 x86_64、IPv4。五个协议均通过公网连通测试，两套系统也通过了公信证书签发、订阅认证、重启恢复、内核切换和失败回退，以及卸载重装。五协议也已通过公网 IPv6 连通测试，IPv6 订阅已在隔离环境验收，分享链接已通过 v2rayN 导入检查。详见 [v1.1.0 发布说明](https://github.com/LauritzWu/jc-vps/releases/tag/v1.1.0)。

首页包含服务状态、服务管理、客户端与订阅、网络与防火墙和系统工具。支持数字选择和子菜单按 0 返回。主菜单在未部署时回车进入安装，已部署时需输入 0–7 的菜单序号，直接回车会再次提示。底部显示系统、接口地址和服务状态。安装后，首页还显示五个节点的配置端口、REALITY SNI、TLS 证书有效期和本机订阅发布状态。在「3 服务状态」可查看本机监听和最近 50 条运行日志。服务器地区通过 ipwho.is 按 VPS 公网出口 IP 查询并缓存 24 小时。在「系统工具 → 手动覆盖服务器地区」可手动设置，已保存的地区优先使用。

首次运行自动安装 `jc` 快捷命令，并通过 APT 补齐缺失的 jq、qrencode、OpenSSL、iproute2 和 flock。在支持大小写快捷命令的版本中，输入 `jc` 或 `JC` 都可打开菜单。已有 `duo` 的用户可运行一次 `duo`，新版会自动安装 `jc`。主菜单选「一键安装 sing-box」，按顺序选择内核、输入域名和公网节点地址（IPv4 或 IPv6）、分配端口、生成或填写 UUID，最后确认安装。

## 卸载和重装

主菜单选「2 完整卸载 sing-box 和 JC」后，输入 `1` 确认，输入 `0` 或直接回车取消。确认后会停止 JC 服务、移除官方软件包，并删除 JC 节点配置、凭据、订阅文件和快捷命令。Caddy 网站及订阅路由定义、证书、防火墙和手动保存的备份会保留。重新安装时请使用上面的一键命令。若 VPS 仍部署了旧版独立的 REALITY 或 Hysteria 2 服务，请先迁移并移除旧服务，再卸载五协议安装。

## 新 VPS

确认域名直指 VPS，公网 TCP 80 可用于 Caddy 签发和续期，随后选主菜单的「一键安装 sing-box」。每次安装选择一种节点地址。选择 IPv6 时，输入不带方括号的公网地址，并确认 VPS 和客户端都具备 IPv6 连通性。下载安装脚本和依赖仍需要 VPS 的 IPv4 出站。安装后按输出在云防火墙放行各协议对应的 TCP 或 UDP 端口。安装确认五个端口已监听后会自动启用开机自启。已有部署可在「服务管理」手动启用。命令行入口见 `bash duo.sh --help`。

## 无自有域名模式（试用）

安装向导第 2 步选「无自有域名」，默认自动检测公网 IP（优先 IPv4），探测 REALITY 握手目标，自动分配端口并生成凭据。「高级调整」可手动填写 IPv4 或 IPv6，并分别选择各协议的 Host 或 SNI。所有节点连接 VPS 公网 IP。VMess WS 不启用 TLS，另外三个 TLS 节点使用 VPS 自签证书和客户端公钥固定。使用「客户端与订阅 → 查看节点链接和配置文件」查看五条链接和二维码。VLESS 和 VMess 可直接导入。HY2、TUIC 和 AnyTLS 需要在客户端设置信任服务器证书，或通过 SSH 下载菜单列出的单节点或聚合 sing-box JSON（已包含公钥固定）。自签模式可在「客户端与订阅 → v2rayN 兼容链接与二维码」确认生成兼容链接。HY2 链接附带证书指纹，TUIC 和 AnyTLS 的兼容链接跳过服务器证书验证。HTTPS 订阅使用自有域名模式。

## 五协议节点与订阅

- 协议为 REALITY、VMess WS + TLS、Hysteria 2、TUIC 和 AnyTLS。可随机选端口，也可指定五个端口。随机检查本机监听，云防火墙还需单独放行。UUID 可生成或指定，三种密码型协议各自生成密码。
- 在「客户端与订阅」选 1 查看五条链接和二维码，选 2 发布单节点和聚合订阅。节点按「协议-城市」命名，优先使用手动设置的地区。已发布的订阅可通过选 2 更新名称。订阅提供 sing-box JSON 和 Base64 链接格式，使用 HTTPS Basic Auth。
- REALITY 默认使用自有域名，也可手选预置站点、自动探测预置站点或手动填写外部握手目标。选外部目标时，该域名仅用于 REALITY 握手和 SNI，其余四个协议的 TLS 证书和 HTTPS 订阅仍需自有域名。自有目标模式使用 REALITY TCP 端口访问订阅，外部目标模式使用 TCP 8443，后者的公网订阅仍待端到端验收。
- 在「客户端与订阅 → 刷新节点地址」可检测 VPS 的公网出口 IPv4/IPv6，或手动填写公网地址。确认后同步更新节点链接和已发布的订阅。若监听配置未覆盖所选地址族，脚本会停止操作。使用 NAT 或额外公网地址时，可手动填写实际入站地址。
- 在「服务管理 → 更换单个五协议节点的端口」可单独换端口。脚本会备份配置并在应用失败时尝试回滚。先放行新端口，再重新导入受影响的节点并复测。
- 在「网络与防火墙」可按 TCP/UDP 放行指定端口或范围；全开只对已启用的本机 UFW 生效，需手动输入 OPEN-ALL 确认。回退可用 ufw status numbered 找到 JC open all 规则，再用 ufw delete 编号移除。
- 在「系统工具 → 查看或更新官方内核」可选择官方 APT 候选版本或指定仓库版本。切换前会下载当前版本作为回退包。运行中的 JC 服务会短暂重启。若安装、配置校验或监听检查失败，脚本会尝试恢复原版本及服务。恢复失败时会显示保留的安装包路径。切换后请用客户端复测。

## 连不上时怎么查

1. 运行 `jc`，选「服务状态」。检查五协议服务是否运行。再运行 `ss -lntup`，核对安装向导列出的端口是否在本机监听。
2. 若本机已监听，从云服务商面板核对入站规则。REALITY、VMess 和 AnyTLS 用 TCP，Hysteria 2 和 TUIC 用 UDP。按安装向导显示的端口逐个检查。
3. 若证书签发失败，检查域名 A 记录是否指向 VPS，公网 TCP 80 是否开放。运行 `journalctl -u caddy -n 50 --no-pager` 查看原因。若域名也有 AAAA 记录，确认对应 IPv6 的 TCP 80 同样可达。
4. 若订阅下载失败，用浏览器打开菜单生成的 HTTPS 地址。匿名访问应要求认证。输入正确凭据后应能下载配置。分享排障信息前，删去节点链接、订阅密码和私钥。
