# VPS 验收清单

在可重建的测试机上执行。记录 JC 提交、系统和架构、sing-box 与 Caddy 版本、客户端版本和测试日期。保存排障日志前删去节点凭据、订阅密码和私钥。

## 每个候选版本

1. 分别选一台计划支持的 Debian 和 Ubuntu 空机，将测试域名的 A 记录指向 VPS。放行 TCP 80 和安装向导列出的 TCP、UDP 端口。
2. 使用 README 的固定提交方式打开菜单并安装。退出后运行 `jc`，确认仍显示同一提交。检查本机监听和 Caddy 证书，再从外部网络导入五个节点并逐个通过代理发送请求。
3. 发布订阅。用外网访问生成的 HTTPS 地址，确认匿名返回 401、正确认证返回 200。导入聚合订阅，检查单节点订阅与相应节点一致。
4. 启用开机启动并重启 VPS。重复外网连接和订阅检查。
5. 用端口冲突和错误 DNS 分别触发失败。检查已有网站、节点与 SSH 的状态，修正条件后重试，记录需要手动清理的内容。
6. 在已有旧版服务的测试机演练升级、回退、卸载和重新安装。卸载后核对 README 约定保留的 Caddy、证书和防火墙状态。

## 作为支持能力发布前

- 证书续期后从外部检查新证书，并复测使用该证书的各协议和 HTTPS 订阅。
- 宣称支持 IPv6 时，从有 IPv6 的独立网络实际连通，记录节点和订阅各自验证到的范围。
- 若使用外部 REALITY 目标，分别确认 VLESS 的 SNI 是选中的站点、其他协议的 SNI 是自有域名，并从公网验证自有域名 TCP 8443 的订阅匿名返回 401、认证返回 200。
